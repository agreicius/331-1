Proposition 2.5.3. Ring homomorphisms.

  1. Subring inclusions are ring homomorphisms.
    🔗
    🔗
  2. The composition of ring homomorphisms is a ring homomorphism.
    🔗
    🔗
  3. Given a bijective ring homomorphism \(\phi\colon R\rightarrow S\text{,}\) its inverse \(\phi^{-1}\colon S\rightarrow R\) is a ring homomorphism.
    🔗
    🔗
  4. If \(\phi\colon R\rightarrow S\) is a ring homomorphism, then \(\phi(R)\) is a subring of \(S\text{.}\)
    🔗
    🔗
  5. A ring homomorphism \(\phi\colon R\rightarrow S\) is injective if and only if \(\ker \phi =\{0\}\text{.}\)
    🔗
    🔗
🔗
